This is a fun and interactive Simon Game that I built using HTML, CSS, and JavaScript. The game tests your memory by showing you a pattern of colors, which you have to repeat in the correct order. Each round, the pattern gets longer and more challenging.

1 - HTML is used to create the structure of the game (buttons, text, etc.).

2 - CSS styles the game to make it look colorful and attractive.

3 - JavaScript adds the game logic, like generating the random pattern, checking your input, and updating the levels.
